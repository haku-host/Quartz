# Вики Haku Host

Пользовательская документация: **https://wiki.haku.host**.

Сайт работает на Quartz 5. Исходники и готовая статика остаются в ветке `v4`: её использует существующая автоматическая синхронизация сервера. Имя ветки не обозначает версию движка.

## Локальная работа

Нужны Node.js 24 и npm 10.9.2 или новее.

```sh
npm ci
npx quartz plugin install --from-config
npx quartz build --serve
```

Статьи находятся в `content/`, настройки сайта и раскладки — в `quartz.config.yaml`, оформление — в `quartz/styles/custom.scss`. Плагины устанавливаются из npm и фиксируются в `package-lock.json`.

## Структура

| Каталог       | Содержание                                            |
| ------------- | ----------------------------------------------------- |
| `start`       | Первые шаги и выбор панели                            |
| `services`    | Выбор услуги и ресурсов                               |
| `billing`     | Аккаунт, оплата, заказ, продление, домены и поддержка |
| `hakustack`   | VDS, питание, терминал, файлы и ОС                    |
| `pterodactyl` | Игры и приложения, файлы, запуск, копии и доступы     |
| `minecraft`   | Java, миры, домены и плагины                          |
| `help`        | Диагностика и перенос проектов                        |
| `about`       | Адреса сервисов и сведения о вики                     |

Пишите по-русски, используйте понятные названия кнопок и проверяемые шаги. Для новых статей задавайте `title`, `description`, `modified: YYYY-MM-DD`. Пути файлов — на латинице в нижнем регистре. Внутренние ссылки: `[[billing/renewal|Продление услуги]]`.

При переносе страницы добавьте прежний путь в `aliases`. Карта прежних адресов хранится в `scripts/legacy-urls.json`. Не публикуйте секреты, данные аккаунтов и скриншоты с персональной информацией. Цены и доступность тарифов направляйте проверять в каталоге и форме заказа.

## Проверка и публикация

```sh
npm run check
npm test
npx quartz build
npm run check:wiki
```

`check:wiki` проверяет ссылки Markdown, выходные HTML-страницы, якоря и перенаправления старых адресов. Папка `docs/` содержит документацию движка и карты сверки статей с исходниками; в пользовательский сайт попадает только `content/`.

Workflow `.github/workflows/deploy.yml` проверяет изменения, собирает сайт и сохраняет `public/` в ветку `v4`. Публикация GitHub Pages выполняется отдельным заданием: её сбой не блокирует обновление папки для основного сайта. Контейнер синхронизации wiki.haku.host копирует `public/` из GitHub примерно раз в час.

Для ручной публикации сначала выполните все проверки и включите результат сборки `public/` в коммит вместе с исходниками. Не исправляйте только файлы на сервере: следующая синхронизация заменит их версией из репозитория.

Обновление от 2026-10-01 использует Quartz 5.0.0, upstream `97a2d05`. Карты проверки функций — `docs/audit-*.md`.
