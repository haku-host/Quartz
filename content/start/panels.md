_Основной маршрут управления услугой. Данные для входа в каждую панель описаны ниже._

| Сервис                                           | Для чего нужен                                       | Как войти                     |
| ------------------------------------------------ | ---------------------------------------------------- | ----------------------------- |
| [Биллинг Haku Host](https://haku.host/dashboard) | Заказ, баланс, продление, тариф, профиль и обращения | Аккаунт Haku Host             |
| [HakuStack](https://stack.haku.host)             | VDS: питание, ОС, терминал, файлы и состояние        | Через HakuID                  |
| [Pterodactyl](https://ptero.haku.host)           | Игры и приложения: консоль, файлы, запуск и бэкапы   | Отдельный аккаунт Pterodactyl |
| [phpMyAdmin](https://pma.haku.host)              | Работа с поддерживаемыми базами MySQL                | Пользователь и пароль базы    |

## Начинайте с карточки услуги

Самый простой путь — [личный кабинет](https://haku.host/dashboard) → нужная услуга → **«Открыть панель»**. Так вы попадёте в подходящий сервис. Оплату и срок действия проверяйте в биллинге, даже если техническая панель открывается отдельно.

## Аккаунты и пароли

На странице «Вход — HakuID» в HakuStack используйте почту и пароль от биллинга. Для игрового сервера в Pterodactyl при первой покупке создаётся отдельный аккаунт; пароль приходит на email. Изменение пароля биллинга не означает изменение пароля Pterodactyl.

Для восстановления доступа используйте форму именно той панели, в которую не получается войти. В Pterodactyl это ссылка **«Установить новый пароль»** на странице входа. Для биллинга — [[billing/account|восстановление аккаунта]].

Пароль Linux-пользователя внутри VDS и пароль базы данных — ещё два независимых набора данных. Их не нужно вводить в форму входа биллинга.

Для phpMyAdmin требуется база на доступном через этот сервис узле MySQL. Уточните доступность узла своей базы в [[billing/support|поддержке]], если он не указан в вашей инструкции подключения.

## Услуга оплачена, но сервер не виден

Проверьте аккаунт и email, затем статус в карточке услуги. Если установка ещё выполняется, дождитесь её завершения. Если услуга активна, а нужная панель пуста, отправьте номер услуги в [[billing/support|поддержку]]. Повторный заказ для исправления доступа не требуется.
