SSH позволяет работать с командной строкой VDS со своего компьютера. SFTP использует SSH для передачи файлов. Для подключения нужны адрес и учётные данные операционной системы сервера.

## Найти данные

В [HakuStack](https://stack.haku.host) откройте сервер и блок **«Детали»** на вкладке **«Обзор»**:

- **IP** — адрес вашего VDS;
- **«Пользователь»** — в панели указан `root`;
- **«Пароль»** — первоначальный пароль; нажмите на скрытое значение или **«Копировать»**.

Если вы уже поменяли пароль в ОС, используйте новый. Пароль учётной записи Haku для SSH не подходит.

[[hakustack/users|Участнику]] пароль в панели показывается только с правом просмотра учётных данных. После восстановления [[hakustack/backups|копии диска]] используйте пароль или ключ из сохранённой системы: показанный в панели первоначальный пароль может не совпадать с ним.

## Первый SSH-сеанс

На компьютере откройте терминал с установленным клиентом OpenSSH: например, Terminal в Linux/macOS или PowerShell в Windows, если команда `ssh` доступна.

В примерах `203.0.113.10` — адрес для документации. Замените его IP своего VDS.

```sh
ssh root@203.0.113.10
```

Если SSH на вашем сервере настроен на другой порт, укажите его через `-p`:

```sh
ssh -p 2222 root@203.0.113.10
```

Здесь `2222` — пример вашего изменённого порта, а не общий порт серверов Haku. Без явного параметра SSH обычно подключается к порту 22. Синтаксис подключения описан в [справочнике OpenSSH](https://man.openbsd.org/ssh.1).

При первом подключении клиент спросит о ключе сервера. Проверьте, что подключаетесь к правильному IP, и сверьте отпечаток ключа через доверенный канал, например браузерную консоль. Для стандартной установки OpenSSH отпечаток Ed25519-ключа можно посмотреть внутри VDS:

```sh
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

Если такого ключа нет, используйте публичный ключ, настроенный вашей ОС. После подтверждения введите пароль. Во время ввода терминал обычно не показывает ни символов, ни звёздочек — это нормально.

## Сменить первоначальный пароль

После входа под `root` выполните внутри VDS:

```sh
passwd
```

Введите новый пароль по подсказкам и сохраните его в менеджере паролей. Не закрывая текущий сеанс, откройте второй и проверьте вход с новым паролем.

Значение **«Пароль по умолчанию»** в HakuStack после этой операции не обновится. Панель хранит первоначальные данные и получает новые при переустановке ОС. Для постоянного доступа также можно настроить SSH-ключи средствами своей операционной системы.

Чтобы завершить SSH-сеанс, введите `exit`.

## Передать файлы по SFTP

В SFTP-клиенте укажите:

| Настройка       | Значение                               |
| --------------- | -------------------------------------- |
| Протокол        | SFTP                                   |
| Сервер          | IP вашего VDS                          |
| Порт            | Порт SSH внутри вашей ОС               |
| Пользователь    | `root` или созданный вами пользователь |
| Пароль или ключ | Данные этого пользователя в ОС         |

Для консольного клиента:

```sh
sftp root@203.0.113.10
```

Другой порт в `sftp` задаётся заглавной `-P`: `sftp -P 2222 root@203.0.113.10`. Для работы SFTP должна быть включена соответствующая подсистема SSH-сервера. Команды передачи описаны в [справочнике OpenSSH SFTP](https://man.openbsd.org/sftp.1).

Небольшие файлы также можно передавать через [[hakustack/files|файловый менеджер в браузере]].

## Частые ошибки

| Сообщение                                | Что проверить                                                                                     |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `Connection timed out`                   | IP, питание VDS, выбранный порт, сетевую доступность и правила firewall                           |
| `Connection refused`                     | Работает ли SSH-служба и слушает ли указанный порт                                                |
| `Permission denied`                      | Имя пользователя, актуальный пароль или ключ, разрешённые в ОС способы входа                      |
| `REMOTE HOST IDENTIFICATION HAS CHANGED` | Не переустанавливалась ли ОС и не изменился ли сервер по этому IP; заново сверьте отпечаток ключа |

Не отключайте проверку ключей ради устранения последней ошибки. После [[hakustack/reinstall|переустановки]] ключ действительно может измениться, но сначала это нужно проверить.

Если SSH недоступен, используйте [[hakustack/console|терминал или SPICE]] для проверки системы. Для обращения в [[help/index|поддержку]] достаточно текста ошибки, времени и UUID; пароль передавать не нужно.
