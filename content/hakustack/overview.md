После [[hakustack/login|входа в HakuStack]] раздел **«Ваши серверы»** показывает карточки доступных VDS. Нажмите **«Перейти»** у нужного сервера.

## Что показывает карточка

| Поле   | Для чего нужно                                                                      |
| ------ | ----------------------------------------------------------------------------------- |
| Имя    | Помогает отличить серверы друг от друга                                             |
| UUID   | Постоянный идентификатор записи сервера в панели; полезен при обращении в поддержку |
| IP     | Адрес для подключения к VDS                                                         |
| Статус | Состояние питания либо отметка **«Заморожен»**                                      |
| CPU    | Показатель загрузки процессора и выделенное количество vCPU                         |
| RAM    | Использование и выделенный объём памяти                                             |
| DISK   | Показатель занятого места и выделенный объём диска                                  |
| Тип    | Название типа сервера в панели                                                      |

Если данные отсутствуют или выглядят устаревшими, откройте страницу сервера и обновите её. Нулевое значение в карточке само по себе не доказывает, что на сервере ничего не запущено: сравните его с [[hakustack/monitoring|показателями внутри ОС]].

## Вкладка «Обзор»

Вверху находятся [[hakustack/power|кнопки питания]] и **«Переустановить»**. Ниже расположены:

- **«Детали»** — IP, состояние питания, CPU, RAM, Storage, ОС и данные входа;
- **«Терминал»** — работа с командной строкой в браузере;
- **«Файлы»** — загрузка, скачивание и редактирование файлов;
- **«Трафик»** — текущая скорость, суммарные счётчики и график сети.

Соседняя вкладка **«SPICE»** открывает [[hakustack/console|экран виртуальной машины]]. Она поддерживается для VM; для других типов серверов панель сообщает о недоступности.

## IP и пароль

В блоке **«Детали»** найдите **IP**, **«Пользователь: root»** и **«Пароль»**. Нажатие на скрытый пароль показывает или прячет его; кнопка **«Копировать»** помещает пароль в буфер обмена.

Метка **«Пароль по умолчанию»** означает первоначальный пароль системы. После первого входа [[hakustack/ssh|смените его внутри ОС]]. Панель не подхватывает такую смену автоматически: отображаемое значение не становится новым паролем `root`.

После [[hakustack/reinstall|переустановки]] заново проверьте данные в **«Деталях»**: панель получает пароль и IP для переустановленного сервера.

## Переименование

1. Измените имя в поле рядом с заголовком сервера.
2. Нажмите **«Переименовать»**.
3. Убедитесь, что появилось сообщение **«Имя сервера обновлено»**.

Это имя в панели. Переименование не меняет hostname внутри операционной системы, DNS-записи или адрес подключения. Пустое имя сохранить нельзя.

## Замороженный сервер

При заморозке панель показывает **«Сервер заморожен — управление недоступно»**. Проверьте состояние услуги и оплату в [[billing/index|биллинге]]. Если причина неясна или услуга уже активна, передайте в [[help/index|поддержку]] номер услуги и UUID. Повторное нажатие кнопок питания не снимает заморозку.
