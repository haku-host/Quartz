В HakuStack есть два средства доступа через браузер: **«Терминал»** на странице **«Обзор»** и отдельная вкладка **«SPICE»**. Они пригодятся, когда нужно выполнить команду без SSH-клиента или проверить, что происходит с системой.

Для обоих способов требуется право доступа к консоли. Если вы [[hakustack/users|участник]], просмотр услуги или файлов сам по себе не открывает терминал.

| Возможность          | Терминал                                  | SPICE                    |
| -------------------- | ----------------------------------------- | ------------------------ |
| Что открывает        | Командную строку внутри системы           | Экран виртуальной машины |
| Где находится        | **«Обзор» → «Терминал»**                  | Вкладка **«SPICE»**      |
| Особенности          | Для VM требуется работающий `incus-agent` | Доступен только для VM   |
| При заморозке услуги | Подключение недоступно                    | Подключение недоступно   |

## Открыть терминал

1. Войдите в [HakuStack](https://stack.haku.host) и откройте сервер.
2. Убедитесь в блоке **«Детали»**, что он [[hakustack/power|включён]].
3. Найдите **«Терминал»**. Панель пытается подключиться при загрузке страницы; если подключения нет, нажмите **«Подключить»**.
4. Дождитесь состояния **«Подключен»**, щёлкните внутри чёрного поля и вводите команды.

Для простой проверки выполните `pwd` или `uptime`. После перезагрузки сервера сеанс может разорваться. Дождитесь запуска и снова нажмите **«Подключить»**. Если сеанс уже открыт, эта кнопка переподключает его.

Для VM терминал зависит от службы `incus-agent` внутри гостевой ОС. Поэтому ошибка терминала сама по себе не означает, что виртуальная машина выключена. Проверьте её через SPICE или [[hakustack/ssh|SSH]]. Если агент отсутствует или не запускается и вы не знаете, как восстановить его для своей ОС, передайте ошибку в [[help/index|поддержку]].

## Открыть экран через SPICE

1. На странице сервера перейдите на вкладку **«SPICE»**.
2. Нажмите **«Подключить»** и дождитесь изображения.
3. Щёлкните внутри экрана, чтобы передавать ввод в виртуальную машину.
4. Если ОС показывает приглашение входа, используйте учётные данные этой ОС. Первоначальные данные доступны на вкладке **«Обзор»**, если вы ещё не меняли пароль.
5. Для закрытия сеанса нажмите **«Отключить»**. Сервер при этом продолжает работать.

SPICE показывает текущий экран системы. Наличие этой вкладки не устанавливает графическое окружение: у серверной ОС на экране может быть обычная текстовая консоль.

Панель рекомендует `spice-vdagent` для лучшей работы SPICE. Его установка зависит от выбранной ОС. Сообщение **«SPICE доступен только для виртуальных машин»** означает, что этот способ доступа не поддерживается для выбранного типа сервера.

## Если подключение не устанавливается

- Проверьте питание и отсутствие заморозки услуги.
- Проверьте, что право доступа к консоли не отозвано. Если завершилась сессия биллинга, [[hakustack/login|войдите заново]].
- Перечитайте сообщение об ошибке, затем повторите подключение. При ограничении частоты запросов дождитесь указанного срока.
- Если соединение рвётся только в одном браузере или сети, проверьте его в другом доступном браузере или подключении.
- При ошибке терминала VM попробуйте SPICE; при проблеме только браузерной консоли проверьте SSH.

Для поддержки запишите UUID, время сбоя, способ подключения и сообщение на экране. Не прикладывайте пароль, содержимое буфера обмена или ссылки подключения с токенами.
