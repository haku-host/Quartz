LuckPerms управляет разрешениями игроков и групп. Команды и функции при этом предоставляет соответствующий плагин: выдача `essentials.home` имеет смысл, когда установлен [[minecraft/essentials|EssentialsX]].

Выберите вариант для своего серверного ядра на [странице загрузки LuckPerms](https://luckperms.net/download). Для Paper используйте Bukkit-версию и [[minecraft/plugins|установку в папку plugins]]. Сборки для прокси и модовых загрузчиков устанавливаются иначе — сверяйтесь с [официальной инструкцией](https://luckperms.net/wiki/Installation).

## Создать группу с двумя правами

Откройте консоль [[pterodactyl/index|Pterodactyl]]. Команды здесь вводятся без `/`; в игре нужен начальный слеш и доступ администратора. `residents` — пример имени новой группы, `PlayerName` — ник игрока, который уже заходил на сервер.

```text
lp creategroup residents
lp group residents permission set essentials.sethome true
lp group residents permission set essentials.home true
lp user PlayerName parent add residents
```

Группа получает два конкретных разрешения, а игрок наследует их через членство. `parent add` добавляет группу, сохраняя остальные. Подробный синтаксис доступен в [справочнике команд LuckPerms](https://luckperms.net/wiki/Command-Usage).

Не выдавайте `*` обычным игрокам: такой шаблон охватывает и административные возможности плагинов. Названия нужных разрешений берите из документации самого плагина.

## Проверить результат

```text
lp user PlayerName parent info
lp user PlayerName permission check essentials.home
```

Первый запрос показывает группы, второй объясняет результат проверки права. Затем игрок без OP должен выполнить `/sethome` и `/home` в игре. Если команда запрещена, проверьте её точное разрешение, запреты и условия действия права, например конкретный мир.

Чтобы убрать добавленную группу:

```text
lp user PlayerName parent remove residents
```

Права могут остаться через другие группы или прямые назначения. Повторите проверку вместо предположения, что удаление одного членства убрало весь доступ.

## Редактор в браузере

Для редактирования этой группы выполните `lp group residents editor`. Откройте выданную ссылку, измените нужные записи, нажмите **Save** и выполните предложенную редактором команду применения. Одного сохранения страницы недостаточно. Порядок описан в [документации веб-редактора](https://luckperms.net/wiki/Web-Editor).

Если `lp` неизвестна, проверьте загрузку плагина и правильность сборки. Если в игре выводится только версия, используйте консоль сервера: у игрока может не быть доступа к командам LuckPerms.
