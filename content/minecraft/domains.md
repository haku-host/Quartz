Если вам нужен поддомен из предлагаемых Haku Host зон, начните с [[billing/domains|настройки домена в биллинге]]. Ниже — вариант для собственного домена у вашего DNS-провайдера.

## Сначала проверьте прямой адрес

Убедитесь, что сервер запускается и принимает подключение по паре адрес:порт из панели. DNS не исправляет остановленное приложение или неверно настроенный порт.

## A-запись

Создайте A-запись для выбранного имени, например `node.example.com`, и укажите реальный IPv4 вашей услуги. В поле адреса не добавляйте порт, `http://` или путь.

После обновления DNS подключение по `node.example.com:порт` должно вести на тот же сервер. Если у провайдера включается HTTP-проксирование, для обычного игрового подключения выберите режим **DNS only**, если вы не используете специально настроенный игровой прокси.

## SRV для Minecraft Java

SRV позволяет Java-клиенту найти порт сервера по доменному имени. Например, чтобы игрок вводил `play.example.com`, настройте:

| Поле       | Пример                                      |
| ---------- | ------------------------------------------- |
| Тип        | SRV                                         |
| Имя записи | `_minecraft._tcp.play` в зоне `example.com` |
| Приоритет  | `0`                                         |
| Вес        | `0`                                         |
| Порт       | Реальный порт из панели                     |
| Цель       | `node.example.com`                          |

`node.example.com` должен разрешаться в адрес услуги. В цель SRV вписывается имя узла, а не IP, URL или адрес с двоеточием и портом. У разных DNS-панелей поля «служба», «протокол» и «имя» могут быть разделены; итоговое полное имя записи должно получиться `_minecraft._tcp.play.example.com`.

Назначение полей A и SRV описано в [справке DNS](https://developers.cloudflare.com/dns/manage-dns-records/reference/dns-record-types/).

![Minecraft Java получает из SRV имя целевого узла и порт, затем через A-запись определяет IPv4 и подключается к серверу.](/assets/illustrations/minecraft-dns.svg)
_Имена в зоне example.com — примеры. В своих записях используйте домен, IP и порт вашей услуги._

## Проверка

Дождитесь обновления DNS-кэша, затем попробуйте подключиться к `play.example.com` без порта. Если прямой адрес работает, а домен нет, перепроверьте полное имя SRV, её цель и порт. Ошибочная AAAA-запись также может направлять клиентов на другой адрес.

Эта схема SRV относится к Minecraft Java. Для Bedrock и других игр проверяйте поддержку своего клиента; стандартный вариант — домен и явно указанный порт.
