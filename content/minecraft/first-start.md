## Подготовьте окружение

После [[billing/ordering|заказа]] откройте услугу и перейдите в [[pterodactyl/index|Pterodactyl]]. Дождитесь завершения установки. Сверьте редакцию игры, ядро, серверную версию и [[minecraft/java|версию Java]] с тем, что собираетесь использовать.

Java Edition и Bedrock Edition не взаимозаменяемы. Для сборки модов нужны совместимые серверные файлы, загрузчик и клиентская сборка.

## Запустите сервер

1. Откройте **«Консоль»** и нажмите **«Старт»**.
2. Следите за сообщениями до завершения загрузки.
3. Если сервер просит принять EULA, прочитайте [условия Minecraft](https://www.minecraft.net/eula). Подтвердите согласие предложенным способом; при ручной настройке это параметр `eula=true` в созданном файле `eula.txt`.
4. Повторите запуск, если первая попытка остановилась на требовании EULA.

Для Java-сервера сообщение `Done` обычно означает завершение загрузки. Если процесс завершился раньше, найдите первую ошибку в консоли: неподходящая Java, отсутствующий JAR и нехватка памяти требуют разных действий.

## Подключитесь

Скопируйте адрес и порт из панели. В Java Edition откройте список серверов клиента и укажите `адрес:порт`; версия клиента должна подходить серверу. В Bedrock адрес и порт вводятся в отдельные поля клиента, где добавление внешних серверов поддерживается.

Не заменяйте выданный порт на `25565` или `19132` самостоятельно. Красивый адрес можно настроить позднее — [[minecraft/domains|инструкция по доменам]].

## Настройте закрытый сервер

Для обычного Java-сервера можно включить список разрешённых игроков из консоли:

```text
whitelist on
whitelist add PlayerName
```

Замените `PlayerName` ником игрока. Команды в консоли вводятся без начального `/`. Для выдачи прав администратора используйте `op PlayerName` только для доверенного аккаунта; обычным игрокам OP не нужен.

Остановите сервер перед ручным редактированием конфигурации. Не отключайте проверку аккаунтов как способ устранить произвольную ошибку входа: сначала разберите точное сообщение.

## Сохраните рабочую копию

После настройки и проверки входа сделайте резервную копию. Только затем добавляйте [[minecraft/plugins|плагины]], моды или меняйте ядро. При проблемах с доступом используйте [[help/connection|проверку подключения]].
