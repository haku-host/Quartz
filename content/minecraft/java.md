Версия Java зависит от конкретного ядра и его версии. Требования плагинов и загрузчиков модов также могут отличаться. Сначала проверьте документацию сборки, затем выбирайте среду в панели.

## Ориентир для Paper

В актуальной [таблице PaperMC](https://docs.papermc.io/paper/getting-started/) указаны следующие рекомендуемые версии:

| Версия Paper | Java |
| ------------ | ---- |
| 26.1 и новее | 25   |
| 1.20–1.21.11 | 21   |
| 1.17–1.19    | 17   |
| 1.16.5       | 16   |
| 1.12–1.16.4  | 11   |
| 1.7.10–1.11  | 8    |

Это рекомендации Paper, а не универсальная таблица для Vanilla, Forge, Fabric и всех старых сборок. При выходе новой версии сверяйтесь с документацией её разработчика.

## Как поменять среду

1. Остановите сервер в Pterodactyl.
2. Откройте **«Запуск»** и найдите доступный выбор образа или среды.
3. Выберите вариант с требуемой версией Java.
4. Запустите сервер и проверьте версию среды и результат в консоли.

Список вариантов задаётся окружением конкретной услуги. Если нужной Java нет, обратитесь в [[billing/support|поддержку]] с версией ядра и текстом ошибки. Название варианта «производительность» не заменяет проверку номера Java и совместимости.

## Частые ошибки

`UnsupportedClassVersionError` обычно указывает, что запускаемый файл собран для более новой Java, чем установленная. Проверьте и ядро, и недавно добавленные плагины.

Ошибки аргументов JVM могут появиться после смены среды. Не переносите длинный набор флагов из другой сборки без проверки. Если сервер перестал запускаться после изменения, верните прежний рабочий вариант и сохраните полный текст ошибки для диагностики.
