В [[billing/services|карточке услуги]] есть блок **«Привязка домена»**. Здесь можно выбрать субдомен в доступной зоне Haku Host и направить его на сервер. Для VDS также предусмотрен отдельный блок **«Обратная DNS-запись (PTR)»**. [[billing/sharing|Участнику]] нужны отдельные права просмотра и управления доменами; для PTR выдаются собственные права. С одним правом просмотра форма изменения не показывается.

## Выбрать нужный тип записи

| Запись          | Для чего нужна                                                  | Что указать               |
| --------------- | --------------------------------------------------------------- | ------------------------- |
| A               | Связывает доменное имя с IPv4 сервера                           | IP сервера                |
| SRV (Minecraft) | Позволяет Minecraft Java находить адрес и порт сервера по имени | Адрес ноды и игровой порт |
| PTR             | Задаёт имя, связанное с IPv4 в обратном DNS                     | Полное доменное имя VDS   |

Для VDS и большинства игровых услуг доступна A-запись. У услуг, определённых как Minecraft, дополнительно доступна SRV, выбранная по умолчанию. Набор вариантов зависит от типа сервера.

Биллинг подставляет адрес из панели: IPv4 для VDS, основной адрес и, для Minecraft, имя ноды и порт. Это подсказка в форме, а не автоматическое создание DNS. Проверьте значения перед сохранением. Уже сохранённые настройки отображаются отдельно и не заменяются без вашего действия.

Если показано, что адрес не удалось определить автоматически, проверьте его в панели и заполните доступные поля вручную. Если нужного типа записи нет в списке, уточните тип услуги у поддержки.

DNS-запись не запускает сервер и не меняет порт приложения. Сначала убедитесь, что сервер доступен по своему выданному адресу.

## Создать A-запись

1. Откройте [«Мои услуги»](https://haku.host/dashboard) → **«Управлять»** → **«Привязка домена»**.
2. В поле **«Субдомен»** введите только желаемую часть имени, например `myserver`.
3. Выберите **«Корневой домен»** из списка.
4. В поле **«Тип записи»** выберите **«A (IP)»**.
5. Проверьте подставленный IPv4 или укажите адрес своего сервера из панели. Если под полем перечислены разрешённые подсети, адрес должен входить в одну из них.
6. Нажмите **«Сохранить домен»** и подтвердите изменение.

После успешного сохранения в блоке отобразятся полное имя, тип записи и IP. Для имени допустимы латинские буквы, цифры и дефисы; имя не должно начинаться или заканчиваться дефисом. Занятый субдомен сохранить не получится.

A-запись не содержит номер порта. Если клиенту вашего приложения требуется порт, указывайте его отдельно при подключении.

## Создать SRV для Minecraft Java

[![Форма привязки домена с типом записи SRV для Minecraft](/assets/screenshots/billing-domains.webp)](/assets/screenshots/billing-domains.webp)
_Форма SRV в карточке тестовой услуги. Значения субдомена, корневого домена, адреса ноды и порта скрыты непрозрачными масками. Картинку можно открыть полностью._

1. Проверьте подставленные адрес ноды и порт; при необходимости сверьте их с [[pterodactyl/network|адресом подключения в Pterodactyl]].
2. В блоке **«Привязка домена»** заполните субдомен и выберите корневую зону.
3. Выберите **«SRV (Minecraft)»**.
4. В поле **«Адрес ноды»** оставьте подставленное или укажите выданное имя ноды. Не подставляйте случайное имя из примера.
5. Введите **«Порт»** из адреса подключения к вашему серверу.
6. Нажмите **«Сохранить домен»**, подтвердите действие и дождитесь обновления DNS.

Биллинг создаёт запись для Minecraft Java (`_minecraft._tcp`). После распространения DNS игроки могут использовать выбранное полное доменное имя без дописывания игрового порта. Этот способ не предназначен для адреса Minecraft Bedrock.

Поле ноды принимает имена вида `msk*.haku.host`; произвольный внешний домен или IP вместо имени ноды не подойдёт. Если панель выдала адрес другого вида, уточните настройку у [[billing/support|поддержки]].

## Изменить или удалить субдомен

Изменения доступны **раз в 24 часа**. Ограничение относится и к удалению: после сохранения нельзя рассчитывать сразу заменить или удалить запись. Если срок ещё не прошёл, кабинет покажет время следующего изменения.

Для удаления нажмите **«Удалить домен»** и подтвердите действие. После подтверждения домен убирается из карточки, а удаление DNS-записи выполняется автоматически. Обновление DNS и очистка кешей могут занять время.

Если вы используете собственный купленный домен, его записи настраиваются у вашего DNS-провайдера. Список «Корневой домен» в биллинге предназначен для доступных в нём зон.

## Настроить PTR для VDS

PTR — обратная запись: при проверке IP она возвращает доменное имя. Она настраивается отдельно от A-записи и не создаёт её автоматически.

1. Откройте карточку **активной услуги HakuStack** и найдите **«Обратная DNS-запись (PTR)»**.
2. Проверьте показанный **IP сервера** и текущую PTR.
3. В поле **«Доменное имя»** введите полное имя, например `server.example.com`, без `https://`, порта и пути.
4. Нажмите **«Сохранить PTR»** и проверьте сообщение об успешном изменении.

IP для PTR определяется по услуге. В поле доменного имени нужно указать именно имя, а не IP. Менять PTR можно **раз в 12 часов**; время следующего изменения отображается в блоке.

Если поле недоступно, прочитайте сообщение рядом с ним. Возможные причины — неактивная услуга, неподдерживаемая подсеть, временная ошибка проверки или запись, ранее настроенная вне этой услуги. Для последнего случая предусмотрена ссылка **«Обратиться в поддержку»**.

## Имя сохранено, но соединение не работает

Сначала проверьте доступ по исходному адресу сервера. Затем сверьте полный субдомен, тип записи, IP или имя ноды и порт. Убедитесь, что после изменения прошло время для обновления DNS.

Если запись выглядит правильно, а проблема остаётся, [[billing/support|создайте тикет]] с номером услуги, доменным именем, временем изменения и результатом подключения по исходному адресу.
