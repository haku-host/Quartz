Во вкладке **Запуск** показаны **Команда запуска**, **Образ Docker** и **Переменные**. Набор полей зависит от шаблона сервера — в Pterodactyl он называется _egg_.

[![Параметры запуска тестового PaperMC-сервера: команда, Java и переменные шаблона.](/assets/screenshots/pterodactyl-startup.webp)](/assets/screenshots/pterodactyl-startup.webp)
_Пример шаблона PaperMC. Версия Java и значения переменных на снимке относятся к тестовому серверу; выбирайте их по требованиям своей сборки._

## Что меняет каждое поле

| Элемент             | Назначение                                                                               |
| ------------------- | ---------------------------------------------------------------------------------------- |
| **Команда запуска** | Показывает, как панель запускает приложение с текущими параметрами                       |
| **Образ Docker**    | Выбирает среду выполнения из вариантов, разрешённых для этого сервера                    |
| **Переменные**      | Задают параметры шаблона: например, имя файла, версию или отдельные настройки приложения |

Команда запуска в этой вкладке отображается для просмотра. Переменные подставляются в неё по правилам шаблона. Поля с пометкой **Read Only** менять нельзя.

Список образов появляется, когда доступны несколько вариантов. Если поле заблокировано или образ назначен администратором вручную, сменить его здесь не получится. Изменение образа выбирает среду для следующего запуска; оно само по себе не заменяет файлы игрового сервера.

## Изменить переменную

1. Прочитайте описание под полем: оно объясняет допустимое значение и назначение параметра.
2. Запишите прежнее значение и создайте [[pterodactyl/backups|резервную копию]], если изменение затрагивает сборку или данные.
3. Измените значение. В этой форме изменения отправляются автоматически после ввода или выбора; дождитесь завершения индикатора сохранения и убедитесь, что нет ошибки.
4. Перезагрузите страницу и проверьте, что новое значение сохранилось.
5. Выполните необходимое для этого параметра действие: перезапуск или установку по инструкции шаблона. Посмотрите результат в [[pterodactyl/console|консоли]].

Права на просмотр и изменение запуска выдаются отдельно. Если вы дополнительный пользователь и поле недоступно, обратитесь к владельцу сервера.

## Сменить версию или ядро

У разных шаблонов версия применяется по-разному: при запуске, установке или ручной замене файлов. Поэтому универсальной инструкции «выберите версию и нажмите рестарт» нет.

1. Уточните требования целевой версии к среде выполнения и совместимость плагинов, модов и мира.
2. Остановите сервер и создайте копию файлов. Для отдельной базы данных сохраните её экспорт.
3. Измените версию или имя файла в доступных переменных, если это предусмотрено шаблоном.
4. Выберите совместимую среду выполнения, если выбор доступен.
5. Установите нужные файлы способом, предусмотренным вашей сборкой. [[pterodactyl/reinstall|Переустановка]] повторно запускает установщик и может изменить файлы, поэтому используйте её только после проверки инструкции шаблона.
6. Запустите сервер и проверьте загрузку и подключение игроков.

В карточке услуги [[billing/services|в личном кабинете]] также могут быть доступны **Egg** и **Startup command**. Эти параметры управляются через биллинг. Перед сменой шаблона сохраните данные и убедитесь, что новая конфигурация подходит вашей сборке.

Если нужного шаблона или среды нет в списке, обратитесь в [[help/index|поддержку]]. Инструкции для Minecraft собраны в [[minecraft/index|разделе Minecraft]].
