Файлы игрового сервера доступны во вкладке **Файлы** и через SFTP. Для небольших изменений удобен браузер, для загрузки сборки и большого числа файлов — SFTP-клиент.

[![Файловый менеджер Pterodactyl: список файлов, загрузка и создание каталога.](/assets/screenshots/pterodactyl-files.webp)](/assets/screenshots/pterodactyl-files.webp)
_Файлы нового тестового сервера. Меню «…» справа открывает действия с выбранным файлом._

Перед заменой мира, ядра, модов или конфигурации остановите приложение и создайте [[pterodactyl/backups|резервную копию]]. Работающее приложение может перезаписать изменяемый файл при сохранении или остановке.

## Работа в браузере

1. Откройте **Файлы** и перейдите в нужную папку.
2. Загрузите файл кнопкой загрузки или создайте текстовый файл через **Новый Файл**.
3. Для правки существующего текстового файла нажмите на его имя, внесите изменения и нажмите **Сохранить содержимое**.
4. В меню `…` доступны переименование, перемещение, копирование, архивирование, распаковка, скачивание и удаление — в зависимости от типа файла и ваших прав.
5. После замены конфигурации запустите сервер и проверьте [[pterodactyl/console|консоль]].

Удаление не отправляет файл в корзину. Перед удалением сохраните нужную копию вне сервера.

В каталоге с более чем 250 записями браузер показывает только первые 250. Для полного списка и массовых операций используйте SFTP.

## Подключение по SFTP

Откройте **Настройки → Детали SFTP**. Скопируйте данные именно этого сервера:

[![Блок Детали SFTP с полями адреса и имени пользователя.](/assets/screenshots/pterodactyl-sftp.webp)](/assets/screenshots/pterodactyl-sftp.webp)
_Реквизиты SFTP находятся в настройках. Значения адреса и пользователя скрыты; для подключения нужны данные вашей панели._

| Поле клиента | Что указать                                                     |
| ------------ | --------------------------------------------------------------- |
| Протокол     | **SFTP**                                                        |
| Хост и порт  | Из поля **Адрес сервера**                                       |
| Пользователь | Полное значение **Имя пользователя**, включая часть после точки |
| Пароль       | Пароль вашего аккаунта **Pterodactyl**                          |

Не подставляйте сюда игровой порт из вкладки **Сеть**. Для SFTP используется отдельный адрес подключения из настроек.

Вход через Haku Billing действует для браузера и не заменяет пароль SFTP. Даже после привязки нужен пароль аккаунта **Pterodactyl** или настроенный SSH-ключ. Если пароль панели неизвестен, [[pterodactyl/access|установите новый]] через её форму восстановления.

Создайте подключение в установленном SFTP-клиенте, перенесите значения из панели и подключитесь. Кнопка **Запустить SFTP** может открыть уже установленное приложение, если в системе настроена обработка ссылок `sftp://`.

Доступ по ключу настраивается через [Аккаунт → SSH-ключи](https://ptero.haku.host/account/ssh): добавьте **открытый** ключ, затем выберите соответствующий закрытый ключ в клиенте. Закрытый ключ храните только у себя. Подробнее — [[pterodactyl/security|безопасность аккаунта]].

SFTP даёт доступ к файлам сервера. Наличие SSH-ключа в аккаунте не означает доступ к командной оболочке узла.

## Загрузить сборку или мир

1. Проверьте, что архив предназначен для сервера и совместим с выбранным ядром.
2. Остановите сервер и сохраните прежние файлы.
3. Загрузите архив в нужный каталог и распакуйте его через меню файла либо передайте готовые папки по SFTP.
4. Проверьте вложенность. Например, файл ядра должен находиться по пути, указанному в [[pterodactyl/startup|параметрах запуска]], а не внутри лишней папки из архива.
5. Сверьте имена файлов и конфигурацию, запустите сервер и проверьте результат.

Распаковка требует дополнительного места: на диске одновременно находятся архив и извлечённые файлы. Удаляйте загруженный архив после проверки, сохранив исходник у себя.

Если SFTP не подключается, проверьте протокол, отдельный порт, полное имя пользователя и пароль Pterodactyl. Дополнительному пользователю также нужно разрешение **SFTP**.
