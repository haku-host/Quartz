Вкладка **Базы данных** позволяет создавать базы MySQL для плагинов и приложений, если это разрешено лимитом услуги. Реквизиты базы отличаются от входа в Pterodactyl и от данных SFTP.

## Создать базу

1. Откройте **Базы данных → Новая база данных**.
2. В поле **Имя базы данных** задайте короткое название латиницей. Форма принимает от 3 до 48 символов: буквы, цифры, подчёркивания, дефисы и точки.
3. В поле **Подключения с** укажите адрес источника, которому нужен доступ. Это адрес клиента, подключающегося к базе, а не адрес самой базы.
4. Нажмите **Создать базу данных** и дождитесь появления записи.

Пустое поле **Подключения с** разрешает подключения с любых адресов при наличии правильных реквизитов. Если вы не знаете, какой исходящий адрес использует игровой сервер, уточните его в [[help/index|поддержке]], чтобы задать подходящее ограничение.

Если кнопки создания нет, проверьте лимит базы и права дополнительного пользователя. Вкладка может быть недоступна без соответствующих разрешений.

## Подключить плагин

Нажмите кнопку с глазом рядом с базой. В окне **Данные для подключения к базе данных** показаны адрес, пользователь, пароль и строка JDBC. Полное имя базы скопируйте из списка: панель может добавить к выбранному названию префикс.

Перенесите данные в конфигурацию плагина:

| Поле плагина    | Значение из панели            |
| --------------- | ----------------------------- |
| Host / Address  | Хост из **Адрес подключения** |
| Port            | Порт из **Адрес подключения** |
| Database        | Полное имя базы в списке      |
| Username / User | **Имя пользователя** базы     |
| Password        | **Пароль** базы               |

Если плагин принимает хост и порт раздельно, разделите их, как требует его инструкция. Не используйте игровой порт, SFTP-порт или `localhost` вместо адреса из панели.

Сохраните конфигурацию через [[pterodactyl/files|файловый менеджер]], перезапустите приложение и проверьте [[pterodactyl/console|консоль]]. Пароль и строку подключения не публикуйте вместе с логами.

## Сменить пароль

В окне реквизитов нажмите **Сбросить пароль**. Панель создаст новый пароль базы. После этого обновите его во всех плагинах и приложениях, которые используют эту базу, и перезапустите их подключение.

Отображение пароля и его сброс зависят от отдельных разрешений. Если дополнительному пользователю нужен только просмотр списка, не выдавайте доступ к паролю.

## Сохранение и удаление данных

Перед обновлением плагина сделайте экспорт базы с помощью совместимого клиента MySQL и сохраните его вне сервера. [[pterodactyl/backups|Резервная копия файлов Pterodactyl]] не создаёт такой экспорт автоматически.

Кнопка удаления базы требует подтверждения её имени. Удаляются и сама база, и все её данные; отменить действие нельзя. Смена пароля достаточна, если требуется лишь отозвать старые реквизиты.

Если подключение не работает, сверьте полное имя базы, пользователя, пароль, адрес с портом и ограничение **Подключения с**. При обращении в поддержку передавайте текст ошибки без пароля.
